# Prompt para continuar GlucoGuía

Actúa como desarrollador senior de producto digital en salud. Toma este proyecto React + Vite llamado GlucoGuía y conviértelo en una aplicación lista para producción, manteniendo estos límites:

- No calcular dosis de insulina.
- No diagnosticar.
- No reemplazar indicaciones médicas.
- Proteger datos sensibles.
- Mantener UX clara, accesible y mobile-first.

Objetivo de la siguiente fase:

1. Conectar Firebase Auth con Google y email/password.
2. Reemplazar localStorage por Firestore.
3. Crear colección `patients` con ownerUid.
4. Crear subcolecciones para glucosa, insulina, medicamentos, comidas y recordatorios.
5. Implementar permisos de cuidador.
6. Agregar notificaciones push para recordatorios.
7. Crear reporte PDF formal.
8. Agregar validaciones de formularios.
9. Agregar tests mínimos.
10. Mejorar accesibilidad y estados vacíos.

Mantén la app en español, con tono humano y claro. Evita promesas clínicas. Cualquier alerta debe decir “sigue tu plan personal” y “contacta apoyo si corresponde”, no dar órdenes clínicas específicas.
